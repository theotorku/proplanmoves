# 60-Day Roadmap

## Days 1–7 — Foundation

- Repository, application shell, design tokens
- Supabase projects and migrations
- Authentication, profiles, roles, RLS
- CI, environment validation, seed data
- Public homepage and admin shell

Exit: owner can authenticate; CI passes; schema is reproducible.

## Days 8–14 — Lead intake

- Public request form
- Validation and confirmation
- Customer deduplication
- Lead list/detail/search/filter
- Notes, assignments, activities
- Audit events

Exit: lead enters system end to end.

## Days 15–21 — Estimation

- Pricing configuration and versioning
- Deterministic calculation engine
- Estimate detail/editor
- Assumptions, warnings, confidence
- Unit and integration tests

Exit: qualified lead produces a reproducible reviewed estimate.

## Days 22–28 — Quotes

- Quote generation and line items
- Discount, expiration, terms
- Printable view
- State transitions and acceptance recording

Exit: approved estimate becomes a valid accepted quote.

## Days 29–35 — Jobs and scheduling

- Quote-to-job conversion
- Job list/detail
- Schedule/date grouping
- Arrival windows and requirements
- Upcoming jobs component

Exit: accepted work becomes a scheduled job.

## Days 36–42 — Dashboard and operations hardening

- Live KPIs
- Lost reasons and conversion metrics
- Better filters and activity timeline
- Idempotency and conflict handling

Exit: owner has reliable operational visibility.

## Days 43–49 — Customer communication foundation

- Notification provider interface
- Email templates and optional delivery
- Quote and booking confirmations
- Communication audit metadata

Exit: communications are controlled and traceable.

## Days 50–56 — Security and release readiness

- RLS verification suite
- Rate limiting and abuse controls
- Accessibility pass
- Performance and error-state pass
- Production deployment rehearsal

Exit: production release checklist passes.

## Days 57–60 — Pilot and productization notes

- Run realistic sample moves
- Document friction and manual steps
- Capture baseline metrics
- Identify reusable modules
- Prepare v0.2 backlog

Exit: ProPlan Moves can begin operating on the platform with known limitations.
