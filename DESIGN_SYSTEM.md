# Design System

## Brand direction

- Dark navy foundation
- White and light neutral surfaces
- Blue/teal operational accent
- High-contrast status colors
- Clear, professional typography
- Logistics and moving imagery rather than generic AI imagery

## Product character

The interface should feel operational, calm, trustworthy, and action-oriented. Avoid excessive gradients, glassmorphism, decorative animation, and dashboard clutter.

## Core components

- App shell and navigation
- Page header
- KPI card
- Data table
- Filter bar
- Status badge
- Detail panel
- Timeline/activity feed
- Form field and field group
- Money input
- Date and arrival-window controls
- Empty, loading, error, and confirmation states
- Printable quote layout

## Accessibility

- WCAG-conscious contrast
- Semantic HTML
- Visible focus states
- Keyboard navigation
- Programmatic labels and errors
- No color-only status meaning
- Responsive layouts from mobile to desktop

## Content rules

- Use plain operational language.
- Show next actions clearly.
- Distinguish internal notes from customer-facing notes.
- Explain preliminary estimates and assumptions.
- Confirm destructive or irreversible actions.
